PART 1: AWS LOGIN & DATABASE CREATION
#AWS Login for student/ Faculty 
Step 1: Login to AWS using the student/faculty portal:

https://d-c3676e6fd8.awsapps.com/start/

Step 2: Search for RDS → Select Create Database → Full Configuration.

Step 3: Configure the database:

Engine: MySQL

Creation Method: Easy Create

Template: Sandbox

Step 4: Enter the following details:

DB Instance Identifier

Master Username

Master Password

Step 5: Click Create Database and wait until the status becomes Available.

Step 6: Copy the database Endpoint and Port (3306) from Connectivity & Security.

PART 2: MYSQL WORKBENCH INSTALLATION & CONNECTION

Step 7: Download and install MySQL Workbench:

https://dev.mysql.com/downloads/workbench/

Step 8: Open MySQL Workbench → Create New Connection and enter:

Hostname: AWS RDS Endpoint

Port: 3306

Username: Master Username

Password: Master Password

Click Test Connection and connect.
